# 怡红快绿

Green Delights，Android 手机上的本地绿植照护工具。根据植物、环境、天气和照护记录，帮助你判断该检查盆土、浇水、暂缓施肥，还是先观察。

本仓库提供安装说明、更新记录和安装包下载。应用源码保持私有。

## 下载与安装

本次候选版本为 **v0.3.2-rc.1**，仅供测试使用。发布后在本仓库的 [Releases](../../releases) 页面下载 `green-delights-v0.3.2-rc.1-10036-arm64.apk`，不要下载自动生成的 Source code 压缩包。

- 支持 Android 7.0 及以上、arm64-v8a 手机。
- 安装前先在旧版“备份恢复”中导出备份，并保存到手机之外。
- 在手机打开 APK，按系统提示允许该文件来源安装。
- 同包名、同签名且构建号更高的 APK 可覆盖升级；不要为了升级先卸载旧版。
- 本包构建号为 `10036`。如果手机已有更高构建号，请保留现有版本。
- Release 附带 `SHA256SUMS.txt`，可用 `Get-FileHash -Algorithm SHA256 <APK路径>` 核对下载完整性。

本候选版本尚未完成真机覆盖升级及完整主流程验收，建议先在测试设备使用。检查通过的具体范围见 Release 说明。

## 能做什么

- 管理多个地点、植物档案、摆放环境和健康状态。
- 根据照护记录生成浇水、施肥和检查建议；水培植物使用对应的检查提示。
- 记录照护行为、归档植物，按地点逐盆处理今日事项。
- 使用本地规则评估换盆条件和摆放环境。
- 保存成长照片、照片备注和照护历史。
- 配置自己的视觉大模型后，识别植物、诊断异常、生成剪枝指导并跟踪复查。
- 导出和追加式导入本地备份。

## 第一次使用

1. 打开 App，确认运行模式为“手机本地”，不需要启动电脑后端。
2. 新建地点，填写城市和摆放环境，再添加植物。
3. 根据实际盆土、光照和养护情况完善档案；实际操作后再记录。
4. 需要天气时，在“运行状态”配置 QWeather；不可用时程序会尝试 Open-Meteo 备用服务。没有网络时天气更新不可用。
5. 需要识别、诊断或剪枝指导时，在“运行状态”填写支持图片输入的 OpenAI-compatible 大模型地址、模型名和 API key。
6. 需要提醒时开启通知权限并测试通知；各手机的省电设置可能影响提醒。

QWeather 配置包括 API Host、项目 ID、凭据 ID 和私钥。模型配置包括 base URL、model 和 API key；地址应使用服务商提供的 HTTPS 接口。凭据由用户自行申请和保管，服务可用性、额度和费用由相应服务商决定。App 不提供内置开发者凭据，也不要求把凭据发给项目维护者。

## 数据与备份

植物、照片和记录保存在手机本地；联网能力会发送相应数据给外部服务，具体见 [数据与联网说明](DATA.md)。备份不包含天气和模型凭据，换机后需要重新配置。备份含照片和地点等个人数据，请自行妥善保存。

导入采用追加模式；遇到同 ID 数据会阻断，不会静默覆盖。升级前请保存备份；不要尝试通过卸载后降级恢复旧版。
